# Участие в разработке

Этот форк развивается только для macOS. Перед изменениями ознакомьтесь с [README](./docs/README.md) и [инструкцией по сборке](./docs/Development.macos.md).

## Запуск и проверка

Для разработки нужен Mac с Python 3.12 или новее:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[build]'
python -m unittest discover -s tests -v
tg-ws-proxy-tray-macos
```

Для проверки упакованного приложения соберите DMG по [инструкции](./docs/Development.macos.md#локальная-сборка-dmg).

## Изменения

Опишите проблему и ожидаемое поведение, обновите документацию при изменении настройки или сборки и проверьте затронутые сценарии. Изменения сетевого ядра должны сохранять работу приложения macOS и консольного режима на Mac.

При сообщении об ошибке укажите версию приложения и macOS, архитектуру Mac, источник сборки, шаги воспроизведения и относящиеся к ошибке сообщения журнала.
