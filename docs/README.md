# TG WS Proxy for Mac

Локальный MTProto-прокси для Telegram Desktop на macOS. Передаёт трафик через WebSocket-соединения к серверам Telegram, сохраняя шифрование Telegram.

Основан на [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy).

## Статус проекта

`tg-ws-proxy-mac` — форк с фокусом на macOS. В репозитории оставлены приложение для Mac, сетевое ядро и сборка для macOS. Выпуски форка имеют собственную нумерацию версий; дальнейшая оптимизация продолжается.

Собственные сборки создаются в [GitHub Actions](https://github.com/f4rceful/tg-ws-proxy-mac/actions/workflows/build.yml). Публичных релизов пока нет; готовые DMG доступны в артефактах успешных запусков. [Как собрать приложение и подготовить релиз](./Development.macos.md).

## Установка на macOS

1. Откройте [Build macOS](https://github.com/f4rceful/tg-ws-proxy-mac/actions/workflows/build.yml), выберите успешный запуск и скачайте архив из **Artifacts**. Распакуйте его: `TgWsProxyMac_universal2.dmg` — универсальная сборка для Apple Silicon и Intel.
2. Откройте образ и перенесите `TG WS Proxy Mac.app` в папку **Программы (Applications)**.
3. Запустите приложение. Если macOS попросит подтвердить открытие, перейдите в **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.
4. Найдите значок приложения в строке меню и подключите Telegram по инструкции ниже.

Минимальная версия macOS, заданная для сборок форка:

| Mac | Версия macOS |
| --- | --- |
| Intel | 11.0 и новее |
| Apple Silicon | 11.0 и новее |

## Подключение Telegram Desktop

### Через ссылку

1. Нажмите значок TG WS Proxy Mac в строке меню.
2. Выберите **«Открыть в Telegram (127.0.0.1:1443)»**.
3. Подтвердите подключение прокси в Telegram Desktop.

Если Telegram не открылся, выберите **«Скопировать ссылку»**, отправьте её в **«Избранное»** в Telegram Desktop и нажмите на неё.

### Вручную

В Telegram Desktop откройте **Настройки → Продвинутые настройки → Тип подключения → Прокси** и добавьте прокси:

| Поле | Значение |
| --- | --- |
| Тип | MTProto |
| Сервер | `127.0.0.1` |
| Порт | `1443` |
| Secret | Полное значение параметра `secret` из ссылки «Скопировать ссылку» |

Если вы изменили адрес или порт в настройках приложения, укажите свои значения. Приложение должно оставаться запущенным, пока Telegram использует этот прокси.

## Интерфейс macOS

Окна подключения и настроек используют нативный AppKit. На macOS 26 и новее включаются системные поверхности и кнопки Liquid Glass; на macOS 11–15 используются стандартные полупрозрачные окна.

Приложение сохраняет привычное управление из строки меню и последовательные диалоги настроек. Каждый диалог меняет один параметр; «Закрыть» отменяет изменения. После последнего шага настройки сохраняются и приложение спрашивает, нужно ли перезапустить прокси. Сохранение, перезапуск и проверка обновлений выполняются в фоне.

## Управление из строки меню

- **Открыть в Telegram (адрес:порт)** — подключить прокси через ссылку.
- **Скопировать ссылку** — скопировать параметры подключения.
- **Перезапустить прокси** — перезапустить соединения.
- **Настройки…** — изменить параметры прокси.
- **Открыть логи** — посмотреть журнал работы.
- **Страница релиза на GitHub…** — открыть релизы этого форка.
- **Выход** — остановить прокси и закрыть приложение.

## Как работает

```text
Telegram Desktop → локальный MTProto-прокси → WebSocket (TLS) → серверы Telegram
```

Telegram Desktop подключается к прокси на вашем Mac. Прокси определяет нужный дата-центр Telegram и устанавливает WebSocket-соединение с ним. Если этот путь недоступен, приложение пробует резервные способы подключения согласно настройкам.

Для основного режима отдельный сервер не нужен. Cloudflare Worker и собственный Cloudflare-домен настраиваются дополнительно.
